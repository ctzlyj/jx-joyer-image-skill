# 0.2.0：同步独立 Skill 可复用的工作流改进

## 基线与范围

从仓库 `2c72b00`（0.1.1）升级，对照 Web 应用 `41dbd2c` 的共享行为。仅更新本仓库和个人 Skill，不部署 Web、外站或桌面，不更换固定网关/模型，不迁移用户历史或 Key。

| Web 改进 | 独立 Skill 对应行为 |
| --- | --- |
| 手工文案不依赖自动补齐 | 原实现已支持；新增无自动文案时首次生成及失败重试均保留卖点、长短标题的回归 |
| 任务进度与失败图重试 | 工作台逐图持久状态、实际像素、原始输入快照、单张/全失败重试、跨进程互斥、保留成功图 |
| 全部/选中图片下载 | 无模型调用的 ZIP 导出，只允许当前任务内已成功的输出图片 |
| 按行提示词队列 | 支持一行一条，保留旧 `---` 分隔符对多行提示词的兼容 |
| 网关失败诊断 | 状态分类、尝试次数、非瞬态拒绝不重试、504/传输超时分类、不回显原始响应或传输异常 |
| 本地增强保留 | 将已验证的参考图完整性检查脚本及测试纳入仓库，保留禁止粗矩形源图回贴的操作规范 |

浏览器草稿/粘贴/导航/Web Vitals/可见性轮询、ERP、COS 清理、202 HTTP 协议不适用于独立本地 CLI，未引入这些依赖。服装模板审核流程没有专用 CLI，不把普通参考编辑冒充完整影棚功能。

## 已复现问题

- 执行第二张前磁盘清单仍无第一张结果；改为调用前写入 running、完成后逐图落盘。
- 429 的 Retry-After 被下一次网络错误沿用；每次尝试独立初始化等待时间，仍遵守最多四次与固定限流。
- 网关/传输错误可能把上游正文写进错误清单；改为有限分类与固定文案，保留状态和尝试次数。
- 导出首次实现可被清单指向输入或元数据；新增失败回归后限制为当前任务 outputs 下可解码图片，禁止越界和原始输入导出。

## 验证边界

- 全量 109 项测试通过，包含两个进程争用同一任务锁及释放后恢复、缺失快照字段不发请求、不改写原状态。
- 安全扫描、Skill 结构检查、依赖一致性及 PowerShell 包装器离线检查通过。
- 仓库隔离环境和原有个人安装环境分别通过 109 项测试；个人安装更新为 0.2.0，只更新本项目包，不升级原有依赖，输出和历史未覆盖。

使用合成图片、假客户端和 MockTransport 进行行为回归，覆盖原文案、参考素材改动、快照缺失/损坏、并发重试、ZIP 范围、CLI 离线查询、传输分类及旧工作流。测试不使用真实 Key，不调用计费模型；不把 Web 的生产验收冒充 Skill 的实机生图验收。

更新保留本地输出与既有运行环境；回退只回退本次源码，不回滚清单或自动重放任务。
